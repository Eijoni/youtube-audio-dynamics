# YouTube Audio Dynamics

A lightweight Manifest V3 Chrome extension that adds a real-time audio compressor and `-0.1 dBFS` peak normalizer directly inside the YouTube video player—with automatic bypass for music tracks and music videos.

Built for watching YouTube without constantly riding the volume slider between whispered dialogue, loud sound effects, and inconsistently mastered uploads.

## Features

- **In-player UI:** Adds a button next to YouTube's Settings gear with a sub-menu (works in default, theater, and fullscreen modes).
- **Color-coded status icon:**
  - **Green:** Active (compressing & normalizing)
  - **Amber:** Auto-bypassed on detected Music / VEVO content
  - **Gray:** Manually disabled
- **Stage 1 — Configurable Compressor:** Adjust **Headroom** (Threshold gets auto-adjusted automatically), **Ratio**, **Knee**, **Attack**, and **Release** in real time, with live Gain Reduction (`GR`) readout. No manual makeup gain—Stage 2 handles output level automatically.
- **Stage 2 — Real-Time `-0.1 dBFS` Peak Normalization:** Dynamically scales post-compressor audio up or down to hit a consistent `-0.1 dBFS` peak ceiling across different videos, gated at `-46 dBFS` so silence doesn't ramp up background hiss.
- **Volume slider compensation:** Divides out YouTube's native volume slider before processing and reapplies it afterward, so lowering the player volume doesn't starve the compressor or fight the normalizer.
- **Automatic Music / VEVO bypass:** Automatically disables processing when playing YouTube Music auto-generated tracks (`- Topic` / `Auto-generated by YouTube.`), VEVO channels, Official Music Video / Audio uploads, or videos in the `Music` category. Clicking the toggle overrides the bypass for the current video.

## Presets

| Preset | Threshold | Ratio | Knee | Attack | Release | Use Case |
| --- | --- | --- | --- | --- | --- | --- |
| **Balanced** | `-24 dB` | `4:1` | `12 dB` | `10 ms` | `250 ms` | Set-and-forget everyday watching (podcasts, commentary, gaming) |
| **Night Mode** | `-36 dB` | `10:1` | `8 dB` | `3 ms` | `200 ms` | Clamps sudden loud spikes while bringing up quiet speech |
| **Custom** | User-defined | User-defined | User-defined | User-defined | User-defined | Moving any slider automatically switches to and saves Custom |

## Installation (Chrome / Chromium / Edge / Brave)

1. Download or clone this repository to a folder on your PC (if downloading as a ZIP from GitHub, extract it first).
2. Open `chrome://extensions` (or `edge://extensions` / `brave://extensions`).
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the folder containing `manifest.json`.
5. Open or refresh any YouTube video tab (`Ctrl+F5`) and click the equalizer icon next to the player's Settings gear.

## Files

- `manifest.json` — Extension manifest (MV3) and content script configuration.
- `page-bridge.js` — Runs in the page `MAIN` world to read live YouTube player metadata for Music/VEVO detection.
- `content.js` — Web Audio DSP chain, adaptive peak normalizer, settings persistence, and player UI injection.
- `styles.css` — Styling for the player bar icon and sub-menu panel.
